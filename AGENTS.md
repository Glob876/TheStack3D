# Правила работы с проектом

## Обязательные коммиты

- Каждое изменение файлов проекта, выполненное агентом, обязательно фиксировать в Git.
- Создавать отдельный коммит после каждого законченного логического изменения; не завершать задачу с незакоммиченными собственными изменениями.
- Перед коммитом проверять diff и выполнять проверки, соответствующие изменению. В итоговом ответе указывать результат проверок и хеш созданного коммита.
- Использовать понятные сообщения коммитов, описывающие сделанное изменение.
- Включать в коммит только изменения текущей задачи. Не коммитить, не отменять и не перезаписывать посторонние изменения пользователя без его указания.
- Не добавлять в Git секреты, локальные настройки, кэши и результаты сборки.
- Если создать коммит невозможно, явно сообщить причину и перечислить оставшиеся незакоммиченные изменения.

## Удалённый репозиторий

- `origin`: https://github.com/Glob876/TheStack3D.git
- Отправлять коммиты в удалённый репозиторий (`git push`) по указанию пользователя.
